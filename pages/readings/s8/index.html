Guía de los cinco ejercicios

Cada carpeta incluye un README con el problema, archivos, comandos del .comm, parámetros editables y opciones de modelización.

Ejercicio Contenido Guía
1 Armadura plana de balcón; Code_Aster y MATLAB README
2 Armadura plana de balcón; datos parametrizados, sin Tecplot README
3 Misma armadura con exportación ASCII a Tecplot README
4 Armadura espacial de aluminio README
5 Viga en voladizo con carga distribuida README

La carpeta original ejercicios se considera el ejercicio1; no se ha renombrado. Los ejercicios 1, 2 y 3 representan el mismo problema con distintas versiones de los archivos.

En los ejercicios 1–4 se usa BARRE para fuerza axial. En el ejercicio5 se usa POU_D_E para flexión Euler-Bernoulli. Cambiar la modelización exige revisar propiedades, apoyos y posprocesamiento; no basta con sustituir el nombre.
